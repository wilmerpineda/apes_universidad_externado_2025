# 📘 Introducción al Curso de Aprendizaje Estadístico

El **Aprendizaje Estadístico** es un conjunto de técnicas que permiten extraer patrones y conocimiento útil a partir de los datos. Este curso se enfoca en los fundamentos teóricos y prácticos del aprendizaje supervisado y no supervisado, proporcionando al estudiante herramientas para construir, evaluar e interpretar modelos predictivos y de segmentación.

El curso se desarrolla con un enfoque aplicado, utilizando ejemplos reales y herramientas computacionales modernas como R o Python para implementar los modelos. A lo largo del curso se abordarán tanto las intuiciones estadísticas detrás de los métodos como su utilidad en contextos de analítica, inteligencia de negocios y ciencia de datos.

## 🎯 Objetivos del Curso

- Comprender los fundamentos teóricos del aprendizaje estadístico.
- Aplicar técnicas de modelación supervisada para resolver problemas de predicción.
- Utilizar métodos no supervisados para descubrir estructuras ocultas en los datos.
- Evaluar y comparar el desempeño de distintos modelos mediante métricas apropiadas.
- Desarrollar pensamiento crítico para interpretar resultados y evitar sobreajuste.

---

## 🧠 Módulo I: Aprendizaje Supervisado

El aprendizaje supervisado se refiere a problemas donde existe una **variable objetivo** (respuesta) y se desea predecir su valor a partir de un conjunto de variables explicativas. Los temas abordados incluyen:

- **Modelos de regresión**: lineal, regularizados (Ridge, Lasso)
- **Modelos de clasificación**: regresión logística, árboles de decisión, k-vecinos más cercanos
- **Evaluación de modelos**: error de predicción, validación cruzada, métricas como MSE, AUC, precisión y recall
- **Prevención del sobreajuste**: selección de variables, regularización, complejidad del modelo

---

## 🔍 Módulo II: Aprendizaje No Supervisado

En el aprendizaje no supervisado no existe una variable objetivo explícita. El objetivo es **descubrir patrones o estructuras subyacentes** en los datos. Este módulo cubrirá:

- **Clustering (segmentación)**: k-medias, clustering jerárquico
- **Análisis de componentes principales (ACP)**: reducción de dimensión y visualización
- **Análisis de correspondencias**: para variables cualitativas
- **Detección de valores atípicos**

---

## 🧰 Enfoque Metodológico

El curso combina sesiones teóricas con actividades prácticas, en las que se espera que el estudiante construya modelos reales, interprete resultados y comunique hallazgos. Se promoverá el trabajo individual y colaborativo mediante ejercicios guiados, estudios de caso y proyectos aplicados.

---

## 📌 Requisitos

Se espera que los estudiantes tengan conocimientos básicos de estadística, álgebra lineal, y programación en R o Python. No es necesario tener experiencia previa en modelos de machine learning, ya que los conceptos serán introducidos desde una perspectiva estadística.

---

Este curso busca formar una base sólida en aprendizaje estadístico, capacitando a los estudiantes para abordar problemas reales de predicción, segmentación y análisis exploratorio de datos de forma rigurosa y crítica.
